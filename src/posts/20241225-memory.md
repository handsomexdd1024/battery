# 20241225 随笔

2021年的6月，厦大附中毕业典礼那天，礼堂响起在附中挺过无数遍的《执着》。贾老师惯例每年为附中创作至少一首原创音乐，而这首歌问世于2016年，在那之前，除了附中原创音乐之外，好像我也无法为这首歌找到别的意义。

> 当梦想受伤 几近失望
>
> 当泪滴下 抹去不安
>
> 借一点星光 把执着擦亮
>
> 胸膛里环抱着希望

毕业典礼那天，我呆坐在礼堂座位上，石鸾屿学姐清亮的歌声响彻礼堂大厅。在我意识到之前，眼泪就已沿着脸颊滴到了校服上衣上。我什么都没有做，甚至都没有拿手臂擦干眼泪……只是放任自己沉默地哭泣。

那时的我不可能料到，此后我所行路途有多么坎坷，我至今也没能重拾自己面对未来的勇气。
